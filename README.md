# Plant Disease Classification Using Logistic Regression

## Project Description
This project predicts whether a plant is affected by disease using environmental parameters and Machine Learning.

## Dataset
The dataset contains 10,000 records.

### Input Features
- Temperature
- Humidity
- Rainfall
- Soil pH

### Target Variable
- 0 – No Disease
- 1 – Disease Present

## Algorithm Used
Logistic Regression

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Model Development
1. Dataset Loading
2. Data Preprocessing
3. Feature Selection
4. Train-Test Splitting (80:20)
5. Feature Scaling
6. Logistic Regression Model Training
7. Disease Prediction
8. Model Evaluation

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC
- Confusion Matrix

## Results
- Accuracy: 77.45%
- Precision: 0.6703
- Recall: 0.1266
- F1 Score: 0.2129
- ROC-AUC: 0.7127

Google Colab and GitHub
